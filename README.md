This Android app is an alarm clock that can use a user-defined local folder containing music and videos, playing them as a playlist for the alarm sound. It also challenges you with a small maths exercise before you can stop or snooze the alarm.

✨ Features:
- Set a one-time alarm or set it to go off on specific days of the week.
- Use a local folder containing music and/or videos as a playlist.
- Solve a math exercise to snooze / stop the alarm.
- It respects your privacy by only accessing the folders you explicitly allow.
- Dark mode support
- The app is available in English and German.


📝Planned Features:
- Update the target version to Android 16.
- Allow an user-defined snooze length. 
- Allow the user to select different difficulty levels for maths exercises.
