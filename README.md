# Math Puzzle Alarm
## An alarm clock that challenges you!

This Android app is an alarm clock that can use a user-defined local folder containing music and videos, playing them as a playlist for the alarm sound. It also challenges you with a small maths exercise before you can stop or snooze the alarm.<br /><br />
✨ Features:<br /> 
- Set a one-time alarm or set it to go off on specific days of the week.
- Use a local folder containing music and/or videos as a playlist.
- Solve a math exercise to snooze / stop the alarm.
- It respects your privacy by only accessing the folders you explicitly allow, by implemenenting Android's Storage Access Framework (SAF).
- Dark mode support
- It supports portrait and landscape mode
- The app is available in English and German.<br /> <br /> 

📝Planned Features:<br /> 
- Allow an user-defined snooze length. 
- Allow the user to select different difficulty levels for maths exercises.
